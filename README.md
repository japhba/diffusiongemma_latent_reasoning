# Does DiffusionGemma do latent reasoning?

Source for the blog post, self-contained for reproduction: all figure inputs are vendored
under `src_data/` (study outputs captured from the original DiffusionGemma experiments) and
every figure regenerates from them on CPU.

## Layout

- `post.md` — the post text (figures referenced from `figs/`).
- `scripts/` — one script per figure plus shared helpers (`payload.py`, `compose_figs.py`,
  `build_html.py`). Each script's docstring states its data provenance.
- `src_data/` — vendored study data (JSON) that the scripts consume.
- `data/` — small per-illustration extracts produced by the `extract_*` scripts.
- `figs/` — committed renders. `figs/parts/card_*.png` are browser screenshots of the
  native-HTML illustration cards (generated by `build_html.py card`, not regenerable offline);
  every other PNG regenerates from `src_data/` via `scripts/plot_*.py`.

## Reproduce

Python 3 with `numpy`, `matplotlib`, `pillow` (no GPU, no network):

```bash
for s in scripts/plot_*.py; do python3 "$s"; done
python3 scripts/compose_figs.py      # composes matrices + card screenshots into appendix figures
python3 scripts/build_html.py        # renders post.md -> post.html
```

Rerunning the figure scripts reproduces the committed PNGs from `src_data/` alone.
