# engels/ — serial-computation battery (n=20)

`battery.py`: the original 20-problem DG-vs-AR battery (crt/count/hard/transform, with
`answer_only` / `answer_first` / `reasoning_first` framings) grounded in the transparency
paper's opaque-serial-depth concept. It is the n=20 half of the posthoc study's n=40
battery (staged there as `posthoc/battery20.py`) and the problem source for
`posthoc/gen_lure_cots.py`.
